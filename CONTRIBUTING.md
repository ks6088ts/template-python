# Contributing

Thank you for improving this project. The documentation is the single source of truth for
procedures; this page only links to it.

1. Set up the environment with the [development guide](docs/development.md#set-up-once).
2. Decide where a change belongs with the
   [engineering guide](docs/architecture/README.md#where-to-change-code).
3. Run the [checks for the changed area](docs/development.md#checks-by-change-type).
4. Update the English and Japanese documentation together when behavior changes.
5. Open a pull request using the template and describe the verification you performed.

Report security issues privately as described in [SECURITY.md](SECURITY.md).
